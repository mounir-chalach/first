# Assets Directory

This directory contains static assets for the MASI Dashboard.

## Required Assets

### logo.png
- Dashboard logo displayed in the sidebar
- Recommended size: 400x400 pixels
- Format: PNG with transparent background
- If missing, the dashboard will show a default emoji icon (📊)

## Adding Your Logo

1. Create or obtain a logo image for your dashboard
2. Save it as `logo.png` in this directory
3. The logo will automatically appear in the sidebar

## CSS Styling

The `styling.css` file contains custom CSS styles for the dashboard.
This file is loaded automatically by Main.py.
